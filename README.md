## 这是什么

SevenMedia Studio 是一个基于 Next.js 的媒体压缩工作台。首页负责介绍与效果对比，视频、图片和音频分别拥有独立的压缩页面；选择文件后可以设置目标大小和质量档位，完成后直接预览、比较体积并下载结果。

项目以本地自托管为主要使用方式。媒体由你运行的服务处理，不依赖第三方云端压缩平台。

## 当前能力

| 能力 | 说明 |
| --- | --- |
| 三类独立工作台 | 视频、图片、音频分别拥有独立路由与格式提示 |
| 保持源格式 | 默认以与源文件相同的文件类型输出 |
| 目标大小 | 根据目标体积与质量档位调整压缩参数；目标过小时给出合理建议 |
| 前后对比 | 图片滑动对比、双视频同步预览、双音频播放器与体积变化展示 |
| 大文件处理 | 浏览器版单文件最大 5 GB；大文件使用分片传输和磁盘会话 |
| 明暗主题 | 全局主题在首页和压缩工作台之间保持一致 |
| 响应式界面 | 适配常见桌面与移动视口，并统一滚动条和交互反馈 |

> 5 GB 是浏览器工作台的上传上限。超大图片当前不适用该模式；大文件能力主要面向视频和音频。实际处理速度和可用上限仍取决于磁盘空间、内存、FFmpeg 编码能力及服务器超时设置。

## 支持的媒体

- **视频**：MP4、WebM、MOV、AVI、M4V、MKV
- **图片**：JPG、JPEG、PNG、WebP、AVIF、GIF、TIFF、SVG 等常见格式
- **音频**：MP3、WAV、M4A、FLAC、AAC / ACC、WMA、AIFF、Opus、Ogg

输出默认保持源文件类型。不同系统中的 FFmpeg 构建可能支持不同的编解码器；遇到无法编码的格式时，请先检查本机 FFmpeg 能力。

## 工作流程

1. 从首页进入视频、图片或音频工作台。
2. 拖入文件，或点击选择文件。
3. 设置目标大小与质量档位。
4. 开始压缩并等待本机引擎完成处理。
5. 预览处理前后结果，确认体积变化后下载。

小文件直接提交处理；较大的文件会自动切换为分片上传、任务轮询和流式下载流程。

## 本地运行

### 环境要求

- Node.js 20 或更高版本
- npm
- FFmpeg 与 FFprobe（视频、音频压缩必需）

确认 FFmpeg 可用：

```powershell
ffmpeg -version
ffprobe -version
```

安装依赖并启动开发环境：

```powershell
npm install
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)。

## 构建

```powershell
npm run typecheck
npm run build
npm run start
```

- Sharp：图片处理

## 部署说明

首页和界面可以部署到常见的 Next.js 托管平台，但完整压缩能力需要：

- 可执行 FFmpeg / FFprobe
- 可写临时磁盘
- 足够的上传与请求时长
- 与目标文件规模匹配的内存和磁盘空间

因此，完整功能更适合部署到自托管 Node.js / Docker 服务器。仅部署到受限的无服务器环境时，首页可以正常访问，但大文件压缩可能受到请求体积、执行时长和临时磁盘限制。

生产环境请将 `SEVEN_MEDIA_DATA_DIR` 配置为持久化磁盘目录，例如 `/data/seven-media-browser`，并确保运行 Node.js 的用户拥有读写权限。不要依赖默认的 `/tmp`：线上请求可能由不同实例处理，实例重启后临时文件也会被清理，上传任务会因此失效。

## 当前边界

- 当前版本只提供媒体压缩，不包含格式转换、视频剪辑或桌面客户端。
- 目标体积无法脱离媒体时长、分辨率和编解码器限制；过小目标会被拒绝并给出建议。
- 任务文件保存在 `SEVEN_MEDIA_DATA_DIR` 指定的目录中；生产部署应补充定时清理、容量监控与访问控制。
